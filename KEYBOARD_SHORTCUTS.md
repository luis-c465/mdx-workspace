# MDX Workspace - Keyboard Shortcuts Reference

## File Operations
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl/Cmd + P` | Quick Open | Open Command Palette to quickly search and open files |
| `Ctrl/Cmd + S` | Save File | Manually save the currently active file |
| `Ctrl/Cmd + W` | Close Tab | Close the current file tab (with unsaved changes check) |
| `F2` | Rename Item | Rename the selected file or folder in the explorer |

## Navigation
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl/Cmd + B` | Toggle Sidebar | Show/hide the file explorer sidebar |
| `Ctrl/Cmd + \` | Toggle Sidebar | Alternative shortcut to toggle sidebar |
| `Tab` | Next Element | Navigate to next focusable element |
| `Shift + Tab` | Previous Element | Navigate to previous focusable element |

## Search
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl/Cmd + F` | Find in File | Search within the currently open document |
| `Ctrl/Cmd + Shift + F` | Find in Workspace | Search across all files in the workspace |
| `Escape` | Close Search | Close search panel or Command Palette |

## Editor
| Shortcut | Action | Description |
|----------|--------|-------------|
| `Ctrl/Cmd + Z` | Undo | Undo last edit |
| `Ctrl/Cmd + Shift + Z` | Redo | Redo last undone edit |
| `Ctrl/Cmd + B` (in editor) | Bold | Make selected text bold |
| `Ctrl/Cmd + I` (in editor) | Italic | Make selected text italic |
| `Ctrl/Cmd + K` | Insert Link | Insert or edit a hyperlink |

## Markdown Shortcuts
| Shortcut | Result | Description |
|----------|--------|-------------|
| `# ` + `Space` | Heading 1 | Start line with `# ` to create H1 |
| `## ` + `Space` | Heading 2 | Start line with `## ` to create H2 |
| `> ` + `Space` | Blockquote | Start line with `> ` to create quote |
| `- ` + `Space` | List Item | Start line with `- ` to create unordered list |
| `1. ` + `Space` | Numbered List | Start line with `1. ` to create ordered list |
| `` ` `` + text + `` ` `` | Inline Code | Wrap text in backticks for inline code |
| `***` | Thematic Break | Three asterisks on a line creates horizontal rule |

## Command Palette Navigation
| Shortcut | Action | Description |
|----------|--------|-------------|
| `↑` / `↓` | Navigate Results | Move up/down through search results |
| `Enter` | Select | Open the selected file |
| `Escape` | Cancel | Close Command Palette without selection |

## Tips
- **Auto-save**: When enabled in settings, files save automatically after 300ms of inactivity
- **Dark Mode**: Toggle theme using the sun/moon icon in the header
- **File Tree**: Right-click files/folders for context menu with additional actions
- **Diff Mode**: Switch to diff mode in toolbar to see changes vs. saved version
- **Source Mode**: Switch to source mode to edit raw markdown

## Browser-Specific Notes
- MDX Workspace requires a Chromium-based browser (Chrome, Edge, Brave, Opera)
- File System Access API is used for direct filesystem access
- Some keyboard shortcuts may vary slightly by operating system

---

**Pro Tip:** Press `Ctrl/Cmd + P` and start typing to quickly jump to any file in your workspace!
